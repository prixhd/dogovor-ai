# CLAUDE.md: онлайн-конструктор юридических документов

## О проекте
Веб-конструктор юридических документов (РФ) с тремя режимами: классический конструктор, быстрое заполнение по карточкам сторон, ИИ-помощник/редактор. Подробности: `docs/`.

## Порядок работы
**Сейчас работаем по `docs/08-mvp-plan.md` (MVP, финальный дизайн).** Название проекта: договор.ai. Референсы дизайна: `design/`. Главный цикл работы: `docs/00-master-plan.md` (цикл этапов, условия остановки). Статус: `STATUS.md`. Дополнительно прочитай `docs/07-infrastructure-and-security.md`.

1. Прочитай `docs/02-product-spec.md`, `docs/03-roadmap.md`, `docs/04-architecture.md`, `docs/05-design-system.md`.
2. Иди по этапам из `docs/03-roadmap.md` по порядку; без вопросов, пока не сработает условие остановки из master plan. Сначала короткий план, потом тесты, потом код.
3. В конце шага: запусти тесты и линтеры, обнови отметку шага в `docs/03-roadmap.md`, сделай коммит.
4. Не уходи за рамки шага. Если решение спорное, запиши вопрос в `docs/02-product-spec.md` → «Открытые вопросы».

## Правила
- Язык интерфейса и текстов: русский. Код и комментарии: английский.
- Стек по умолчанию: Go (api, worker), Next.js + TypeScript + Tailwind (web), PostgreSQL, Redis, MinIO. Отклонение только с записью в `docs/04-architecture.md`.
- ИИ: ключи только на сервере, через интерфейс `LLMProvider`. Правки документа только как структурированный diff, который принимает пользователь.
- Ссылки на нормы права проверять по `knowledge/`, не выдумывать статьи.
- Не добавлять шаблоны документов со статусом «проверен юристом» без подтверждения владельца.
- Никаких секретов в репозитории (`.env` в `.gitignore`).
- Дизайн: тёмная тема, токены из `docs/05-design-system.md`.
