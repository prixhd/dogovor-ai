# 05. Дизайн-направление

> **Обновление от 25.11:** после референсов пользователя (`design/v1.jpeg`, `v2.jpg`) палитра и тема изменены: светлая тема по умолчанию, тёплый крем + коралловый акцент. Актуальная версия: `08-mvp-plan.md`, раздел 4. Ниже первоначальный вариант (тёмный).

> Это предложение под ваше описание: минимализм, футуризм, много чёрного, ощущение простора и свободы, легко понять с первого экрана. Анализ чужих сайтов здесь поверхностный: у dogovor.ru я смог прочитать только текст страницы (основной цвет белый, фирменный акцент #da532c), без скриншотов. Перед финальным дизайном стоит посмотреть 5-7 сайтов (dogovor.ru, Pravoved, Lawyer-ai-сервисы, Linear, Stripe, Vercel) глазами.

## Идея
«Тихий футуризм»: тёмный, спокойный, много воздуха. Юридическая серьёзность передаётся точностью и типографикой, а не тяжёлыми «колоннами и золотом». Ощущение: документы перестали пугать.

## Палитра (тёмная тема по умолчанию)
| Роль | Цвет | Комментарий |
|---|---|---|
| Фон | `#0B0C0E` | почти чёрный, не чисто чёрный |
| Поверхность | `#14161A` | карточки, панели |
| Поверхность 2 | `#1C1F25` | поля ввода, ховеры |
| Линии | `#2A2E36` | тонкие границы 1px |
| Текст основной | `#ECEEF2` | |
| Текст вторичный | `#9AA1AD` | |
| Акцент | `#7C9CFF` | холодный синий-индиго: доверие + технологичность |
| Акцент ИИ | `#B7A6FF` | мягкий фиолетовый для всего, что делает ИИ |
| Успех / риск | `#5FD3A0` / `#FF6B6B` | для проверки договора |

Светлая тема: фон `#F7F7F5`, текст `#14161A`, тот же акцент (проверить контраст ≥ 4.5:1). Бумага документа в предпросмотре всегда светлая: «белый лист на тёмном столе».

## Типографика
- Интерфейс: Inter (или Geist). Заголовки: крупные, лёгкие (weight 500), плотный трекинг.
- Документ в предпросмотре: Times New Roman / PT Serif (как в реальных договорах).
- Шкала: 14 / 16 / 20 / 28 / 44 / 64.

## Пространство и форма
- Сетка 8px, широкие отступы между блоками (96-160px на главной).
- Радиусы 12-16px, тонкие границы вместо теней, мягкое свечение акцента только на главной кнопке.
- Анимации 150-250ms, без «прыгающих» эффектов; уважать `prefers-reduced-motion`.

## Ключевые экраны
1. **Главная:** одно предложение-обещание, одно поле «Какой документ нужен?» (поиск + ИИ), под ним 6 популярных документов. Ниже: «как это работает» в 3 шага, ИИ-блок, FAQ.
2. **Каталог:** поиск, фильтры по категориям, крупные карточки.
3. **Конструктор:** слева анкета по шагам, справа живой лист документа, сверху переключатель режимов (Конструктор / Быстро по карточке / С ИИ), справа выезжающая панель ИИ.
4. **ИИ-правки:** diff-подсветка (зелёный/красный фрагменты) с кнопками принять/отклонить.
5. **Кабинет:** документы, карточки сторон, лимиты ИИ.

## Тон текстов
Простым русским, без «юридического» официоза в интерфейсе. Дисклеймер: короткий и заметный, не прячем.

## Доступность
Контраст, фокус-кольца, управление с клавиатуры, адаптив от 360px.
