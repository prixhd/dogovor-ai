# 06. Юридические моменты и риски

> Не юридическая консультация. Перед запуском проверить у профильного юриста.

| Риск | Что делаем |
|---|---|
| Шаблон содержит юридическую ошибку | Каждый шаблон проверяет юрист, версия и дата проверки в карточке; не публиковать без статуса «проверен» |
| ИИ выдумывает нормы или советует вредное | RAG по базе норм, проверка ссылок, пометка «не подтверждено», дисклеймер, запрет «гарантировать результат» |
| Персональные данные (карточки, реквизиты) | 152-ФЗ: согласие, политика, хранение на серверах в РФ, удаление по запросу, шифрование, минимум данных |
| Передача данных в зарубежный ИИ | Не отправлять лишние ПДн (маскировать ФИО/паспорта там, где не нужны), отразить в политике, оценить провайдера |
| Позиционирование «заменяет юриста» | Явно: сервис помогает составить документ, не является юридической помощью |
| Расходы на ИИ | Лимиты, кэш, потолки токенов, мониторинг стоимости |
| Prompt injection через загруженные договоры | Текст = данные, структурированный вывод, ограничение действий ИИ |
| Авторские права на шаблоны | Писать/покупать собственные шаблоны, не копировать каталог dogovor.ru |

Нужны документы проекта: политика конфиденциальности, пользовательское соглашение/оферта, согласие на обработку ПДн, cookie-баннер.
