# 02. Продукт: что делаем

## Суть
Онлайн-конструктор юридических документов (договоры, трудовые, заявления, претензии, доверенности и т.д.) в двух режимах плюс ИИ-помощник. Ориентир по структуре: dogovor.ru (каталог шаблонов, анкета, скачивание DOCX/PDF, ИИ-чат, проверка договора).

## Зачем (по голосовым)
1. Документ за минуты без юриста.
2. Не однотипные шаблоны: ИИ дорабатывает содержание, меняет «сторону» договора.
3. ИИ-чат бесплатного уровня приводит аудиторию.

## Три режима работы

### Режим A. Классический конструктор (без ИИ)
Каталог → выбор шаблона → анкета (поля, опции условий) → живой предпросмотр → скачать DOCX/PDF. Работает полностью без ИИ.

### Режим B. Быстрое заполнение по карточке
- Пользователь хранит «карточки»: физлицо / ИП / организация (реквизиты, ФИО, ИНН, ОГРН, банк, подписант).
- Выбрал карточку для роли «Работодатель», другую для «Работник»: поля заполнены автоматически.
- Опционально: загрузка/вставка текста с реквизитами, ИИ извлекает поля (ИИ-ассистированный ввод, с проверкой пользователем).

### Режим C. ИИ-помощник и ИИ-редактор
- **Вопросы по нормам:** боковой чат в контексте документа («что значит эта статья?», «какой максимум испытательного срока?»). Ответы со ссылками на нормы (ТК РФ, ГК РФ).
- **Доработка документа:** «сделай в пользу работодателя», «добавь пункт о конфиденциальности», «смягчи штрафы». ИИ предлагает **правки в виде diff** (принять/отклонить каждую), а не молча переписывает.
- **Режим «сторона договора»:** нейтральный / в пользу стороны А / в пользу стороны Б.
- **Проверка договора:** загрузка чужого договора, список рисков и спорных пунктов.
- **Бесплатный ИИ-чат** (лимит вопросов в день) как точка входа.

## Пользовательские потоки (MVP)
1. Гость: каталог → шаблон → анкета → предпросмотр. Чтобы скачать или сохранить, нужен вход.
2. Зарегистрированный: скачивание, сохранённые документы, карточки сторон, история.
3. Гость/пользователь: ИИ-чат с лимитом.

## Границы MVP
**Входит:** 10-15 шаблонов (трудовой договор, ГПХ/оказание услуг, подряд, аренда, купля-продажа, займ, NDA, доверенность, расписка, претензия, заявление об увольнении, акт), три режима, DOCX/PDF, аккаунты, карточки, ИИ-чат и ИИ-правки.
**Не входит:** 800+ шаблонов, электронная подпись, согласование с контрагентом, мобильное приложение, платёжные пакеты, калькуляторы.

## Принципы (антицели)
- ИИ не «юрист»: везде явный дисклеймер, не выдавать выдуманные нормы. Ссылки на статьи проверяются по нашей базе норм, а не только по памяти модели.
- Не переписывать документ молча: все ИИ-правки видны и принимаются пользователем.
- Не хранить лишние персональные данные; карточки удаляются по запросу.

## Метрики успеха
Время от входа до готового документа < 5 минут; доля завершённых анкет; доля скачиваний; число ИИ-вопросов, перешедших в создание документа.

## Решения владельца проекта (25.11.2026)
1. **Юрисдикция:** только РФ и российское законодательство (ТК РФ, ГК РФ и др.).
2. **Монетизация:** пока всё бесплатно. Платные тарифы обдумаем позже, архитектуру делаем так, чтобы лимиты и тарифы можно было добавить без переписывания (таблица `plans`, счётчики использования).
3. **Юридическая проверка шаблонов:** решение отдано мне, моё решение ниже.
4. **Вход обязателен** для скачивания и сохранения документов: документы и карточки хранятся в профиле.

## Моё решение по юридической проверке шаблонов
- На этапе разработки шаблоны пишутся по тексту законов и типовой практике, у каждого статус `draft` («не проверен юристом»).
- В интерфейсе у `draft`-шаблонов виден пометка и дисклеймер. Публичный запуск разрешён только после того, как юрист (внештатный, разовая проверка 10-15 шаблонов) выставит статус `reviewed` с датой.
- Для бесплатного запуска это самый дешёвый честный вариант. Заменить это решение может только владелец проекта.
