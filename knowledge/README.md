# База норм для ИИ (MVP)

Краткое изложение статей ТК РФ и ГК РФ, нужных для шаблонов MVP. ИИ получает найденные фрагменты в промпте и обязан ссылаться только на них; ссылка на статью, которой здесь нет, помечается «не подтверждено».

Формат: каждый фрагмент начинается с заголовка `## <Кодекс>, ст. <номер>. <название>`. Кодекс: `ТК РФ` или `ГК РФ`.

**Важно.** Это пересказ, а не официальный текст. Перед публичным запуском юрист должен сверить фрагменты с актуальной редакцией (pravo.gov.ru) и при необходимости заменить их точными цитатами. Источник истины: официальный опубликованный текст кодексов.
